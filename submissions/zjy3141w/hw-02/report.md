## 3. 解析核算

取标定点 (0 mm,220 px) 与 (20 mm,180 px)，设 r=kh+b：

```text
k = (180 − 220) px / (20 − 0) mm = −2 px/mm
b = 220 px − (−2 px/mm) × 0 mm = 220 px
r = 220 px − (2 px/mm) × h
h = (220 px − r) / (2 px/mm)
```

以 h 用 mm、r 用 px 表示数值，即 `h=(220−r)/2`。斜率为负，说明高度每增加 1 mm，行号减小 2 px。

用中间标定点交叉检查：

```text
h = (220 − 200) px / (2 px/mm) = 10 mm
```

M07 的实际程序输出为 205 px，代入：

```text
h_calc = (220 − 205) px / (2 px/mm) = 7.5 mm
Δh = h_calc − h_model = 7.5 mm − 7.5 mm = 0 mm
```

解析结果与程序模型输出一致；零差异只描述本次确定性模型计算，不表示实际仪器没有误差。以上推导由 AI 协助整理，本人独立核验尚待补充。

M09 的 r 和 h 为 null。null 不具有数值含义，不能代入标定式，也不能转成零。作为对照，M01 的真实输入为 0 mm，且成功定位条纹于 220 px，属于有效零高度；M09 没有条纹定位结果，属于缺测。

## 4. 同一命题怎样更新

原命题：高度升高时行号减小；遮挡后应记缺测，不能填成 0 mm。

在本次程序模型核对范围内，该命题得到支持。M01–M03 的行号随高度单调减小，M07 支持中间点的线性恢复关系；M08/M09 表明固定高度仅改变可见性后，输出从有效读数变为 null。因此，“没读到条纹可写 0 mm”的教学建议被 M01 与 M09 的语义差异否定。

仍不能确认的是实际设备在遮挡、噪声和几何变化下的表现。程序核对没有提供真实设备精度或不确定度证据，也不能替代实验台的完整操作流程。此处是报告中的分析，尚未保存为实验台 after 更新。
