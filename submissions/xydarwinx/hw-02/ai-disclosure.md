# AI 使用声明

模式：actual-ai。

- **工具、版本、日期**：OpenAI Codex；GPT-6-sol。使用日期：2026-10-15、2026-10-18（北京时间）。
- **任务相关请求摘录**：用户要求核对课程网站中 10 月 21 日截止的作业，完成无需现场实测的部分；后续要求 AI 完成除最终 Git 提交外可完成的工作，并询问“用证据更新判断”的填写方法。
- **任务相关回应摘录**：AI 依据正式任务书选择 B 案例，建议“仅删零速→错误填零→正确标 null→固定策略只关过渡扰动”的单变量顺序；给出 5/100=5%、6/100=6% 的门禁核算与认识更新文字。
- **采用的帮助**：用户使用了 AI 提供的预测候选思路并将首次判断以 90/100 信心在实验台锁定。AI 整理要求、检查官方合成模型、拟写报告与本声明，随后按用户实际导出的 R01–R07 和四张截图核对数值。离线实验台的点击运行、截图和原始 JSON 导出由用户完成。
- **采纳与修正**：采用 R01–R04 的单变量对照、R05–R07 的独立计数核验，以及初始四格和更新四格的证据组织。AI 曾给出适用于两种不同首次预测的“未被支持”栏备选文字，首次保存时两种说明被一并粘入；后来依据实际首次命题修正该栏并重新导出。
- **独立核验与边界**：报告逐式列出 5/100、6/100、t=7 s 运动门禁和停车里程的公式、数值代入及单位，逐项与 record.json 的 R01–R07 核对。181 个显示点、60 个无效点和 39 个漏筛点亦与导出记录核对。源码模型的预核算只作辅助，实际实验读数以原样导出的 JSON 和真实截图为准。实验是教学合成，不声称现场实测、硬件精度或标准 IRI。

本声明只保留作业相关摘录；不包含个人隐私信息。
